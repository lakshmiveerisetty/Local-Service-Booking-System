# Local Service Booking System

## About the Project
A web-based application that allows customers to view available services, book services, check booking status, and cancel bookings. Admins can manage services dynamically.

## Technologies Used
- Java
- JSP and Servlets
- JDBC
- MySQL
- HTML and CSS
- Apache Tomcat 11

## Features
- User Registration and Login
- Dynamic Service Listing
- Book Services
- View My Bookings
- Cancel Bookings
- Admin Service Management

## Database
Database Name: `local_service_booking`

Tables: `users`, `services`, `bookings`

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse IDE.
3. Create the MySQL database and tables.
4. Configure the database connection in `DBConnection.java`.
5. Add the required MySQL JDBC driver.
6. Configure Apache Tomcat 11.
7. Run the project on the server.
